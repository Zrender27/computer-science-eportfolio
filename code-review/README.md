# Code Review

## CS 499 Computer Science Capstone

This code review was completed as part of my CS 499 Computer Science Capstone ePortfolio. The purpose of the review was to evaluate previously completed computer science artifacts, identify opportunities for improvement, and develop a plan for enhancing the artifacts across three major areas of computer science.

The code review examines the following artifacts:
### Software Design and Engineering
**Smart Thermostat Project**

This artifact was reviewed to identify opportunities to improve software organization, maintainability, input validation, error handling, and overall software design.

### Algorithms and Data Structures
**CartPole Reinforcement Learning Project**

This artifact was reviewed to evaluate the algorithms used within the reinforcement learning implementation and identify opportunities to improve performance analysis, evaluation methods, and the organization of the algorithmic logic.

### Database Development
**Animal Shelter Database Project**

This artifact was reviewed to identify opportunities to improve database organization, validation, query functionality, data handling, and maintainability.

## Purpose of the Code Review

The code review allowed me to critically evaluate my previous work before implementing the enhancements presented throughout this ePortfolio. During the review, I examined the existing functionality of each artifact, identified strengths and weaknesses, and developed enhancement plans aligned with the CS 499 course outcomes.

The completed enhancements and supporting narratives can be viewed in the corresponding sections of this ePortfolio:

- [Algorithms and Data Structures](../algorithms-data-structures/)
- [Database Development](../database-development/)
